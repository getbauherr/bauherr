# Bauherr

**An open-source AI software factory. Agents take your tickets through gated stages; you approve the plan, not every keystroke.**

## Start

```
npx bauherr init
```

Requires Docker with Compose and Node 22.14+. No clone, no build. Details: [Quick start in the README](https://github.com/getbauherr/bauherr#quick-start).
