# Redesign mockups

Approved reference designs for the UI redesign. Palette: Indigo + Emerald (owner, 2026-11-26).

| File | Shows |
|---|---|
| `Main.dc.html` | App shell: sidebar, header, page frame |
| `Inbox.dc.html` | Inbox: only items awaiting the owner, a "why you" line, inline decide |
| `Board.dc.html` | Factory board: stage lanes, ticket cards with state chip, left grip handle, right menu |
| `Ticket.dc.html` | Ticket page: criteria and constraints, run timeline, decision log |
| `Chat.dc.html` | assistant-ui thread and composer, tool call states, recommendation card |

They are in the Design canvas format (`.dc.html`). Read the markup for layout, tokens and copy; build with shadcn/ui and assistant-ui, never by copying the markup.
