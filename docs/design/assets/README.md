The cornerstone mark and the wordmark. `bauherr-mark.svg` is drawn for light surfaces (outline `ink` #171a1f, stone `accent` #2457c5); `bauherr-mark-dark.svg` for dark surfaces (outline #e9ebee, stone #8db1ff). Use the mark at 16, 20, 24 or 32px; keep one mark width of clear space; never recolor, rotate or place on an accent fill. The wordmark is for the cover, the login page and documents only; it sets the name in Archivo 600 and needs the font loaded or a fallback sans.
