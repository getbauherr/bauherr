The cornerstone mark and the wordmark. `bauherr-mark.svg` is drawn for light surfaces (outline `ink` #16162a, stone `accent` #5b35e8); `bauherr-mark-dark.svg` for dark surfaces (outline #ebebf5, stone #a594ff). Use the mark at 16, 20, 24 or 32px; keep one mark width of clear space; never recolor, rotate or place on an accent fill. The wordmark is for the cover, the login page and documents only; it sets the name in Archivo 600 and needs the font loaded or a fallback sans.
